# Diagramas prontos para entrega

Arquivos gerados:

- `uml-class-diagram.puml` (Diagrama de Classes)
- `uml-sequence-feed.puml` (Diagrama de Sequencia - Feed)
- `uml-sequence-like.puml` (Diagrama de Sequencia - Like)
- `uml-architecture.puml` (Diagrama de Arquitetura)
- `der-dbdiagram.dbml` (DER para dbdiagram.io)

## Como visualizar agora

1. Abra qualquer arquivo `.puml` no Cursor/VSCode.
2. Com extensao PlantUML instalada, use **Preview Current Diagram**.
3. Exporte em PNG/PDF pelo preview.

## DER

1. Acesse [dbdiagram.io](https://dbdiagram.io/).
2. Crie um diagrama novo.
3. Cole o conteudo de `der-dbdiagram.dbml`.
4. Exporte PNG/PDF.
